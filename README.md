# Multimedija - detekcija saobraćajne trake

Sistem za detekciju saobraćajne trake na slikama i video snimcima, u Python-u uz OpenCV.

Kod, izveštaj i rezultati nalaze se u folderu [zadatak](./zadatak/), a ceo opis rešenja je u [zadatak/README.md](./zadatak/README.md).

```bash
cd zadatak
pip install -r requirements.txt
python main.py --all-images
python main.py --all-videos
python -m pytest tests -v
```
